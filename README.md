# Data Harvest Labs

Data Harvest Labs is a genomic data analysis and statistical consulting company founded in Srinagar, Kashmir. We work with researchers, universities, and breeding programs to turn raw genotype data into publication-ready results.

Our services cover SNP data analysis, GWAS, PCA & population structure, heritability estimation, ANOVA, data visualisation, report writing, and hands-on genomics training for students and researchers.
